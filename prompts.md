# Key AI Prompts Used

1. Generate a Streamlit architecture for a job matching app with embedding retrieval, ranking, feedback, and resume tailoring.
2. Create a Python data cleaning pipeline for job postings with deduplication and structured columns.
3. Implement FAISS retrieval using SentenceTransformers for matching resumes to job descriptions.
4. Write a multi-stage ranking function that combines semantic similarity, skill overlap, salary fit, and hard filters.
5. Build a simple adaptive feedback mechanism using accept, skip, and reject actions.
6. Draft a tailored resume generation function that emphasizes skills from the selected job posting.
